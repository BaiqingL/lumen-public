What the kit contains

The kit contains editable LGPL renderer and frame sources, geometry headers, shaders and generator, the narrow Lumen integration source needed to apply those changes, six original Lumen object files, the original MIT parser archive, its adapter source and dependency lockfile, notices, and practical rebuild and relink scripts. It does not include the unrelated private application source, media samples, or publisher signing credentials.

The supplied materials rebuilt a native library byte-identical to the listed hash. A modified geometry header was also rebuilt and linked successfully. The native source, objects, archive, build scripts and notices are unchanged from that validation; this issued archive adds the approved permission and release metadata.

Rebuild and relink

Extract the ZIP and follow its README.md. The tested toolchain is Harmony native SDK 6.1.1.125 / API 24, OHOS Clang 15.0.4, with Python 3.10 or later. In PowerShell, from the extracted kit:

python -X utf8 rebuild.py --sdk 'C:/Program Files/Huawei/DevEco Studio/sdk/default/openharmony/native' --verify-inputs

This verifies the supplied inputs and builds build/liblumencapabilities.so without the private repository or a network connection. After editing the native sources, omit --verify-inputs because the original hashes will intentionally differ.

The included replacement helper creates an unsigned HAP. Signing and installing a modified app require your own matching Huawei credentials and a separate test environment. Modified-HAP signing and installation have not been demonstrated. The parser archive is reused; its preserved notices describe the historical runtime-provenance limits.
