Included materials and verification

The kit includes editable LGPL renderer, frame and shader sources, geometry and lifecycle headers, the generator, narrow Lumen integration source, six original application objects, the MIT parser archive and its source references, notices and standalone rebuild scripts. It excludes unrelated application source, media and publisher signing credentials.

Pristine and repeat rebuilds reproduce the native library above byte for byte. A modified geometry header changes both consumers and links successfully; replacing the native library in a HAP preserves all other archive members and removes the original signing block. The kit records dated distribution notices and their source overlays in its manifest and provenance.

Permission and licenses

Read the Lumen native relinking permission (Markdown). Its existing approved grant covers the listed original materials for rebuilding, relinking, own-use modification and debugging. The full application remains private. Third-party licenses and rights are unchanged.

Rebuild and relink

Extract the ZIP and follow README.md. The tested native SDK is Harmony 6.1.1.125 / API 24, OHOS Clang 15.0.4. From the extracted kit:

python -X utf8 rebuild.py --sdk 'C:/Program Files/Huawei/DevEco Studio/sdk/default/openharmony/native' --verify-inputs

The build uses the supplied contents and installed SDK. After editing sources, omit --verify-inputs because their original hashes intentionally differ. The helper creates an unsigned HAP; recipient signing and installation require matching personal Huawei credentials and a separate test environment, and have not been tested. The parser archive is reused with the historical provenance limits described in its notices.
