Included materials and verification

This update adds local PGS and VobSub subtitle decoding through a minimal FFmpeg 9.0.1 build. The kit includes the complete upstream source archive, exact patch, configuration, build recipe, headers, matching libraries and licenses. It also retains the renderer and parser materials, three editable native units, seven original application objects and the bitmap integration archive needed for relinking.

Pristine and repeat rebuilds reproduce the native library above byte for byte. A recipient-style modification to FFmpeg's PGS decoder was rebuilt and relinked successfully; unsigned HAP replacement preserves all other package members. The kit contains no unrelated app UI source, media or publisher signing credentials.

Permission and licenses

Read the version-specific native relinking permission (original text). It covers the expressly listed original materials for rebuilding, relinking, own-use modification and debugging. Third-party license rights and historical grants remain unchanged.

Rebuild and relink

Extract the ZIP and follow README.txt. The standalone native SDK is Harmony 6.1.1.125 / API 24, OHOS Clang 15.0.4:

python -X utf8 rebuild.py --sdk '<SDK>/openharmony/native' --verify-inputs

The included FFmpeg source recipe was tested with Ubuntu/WSL and clang 21.1.8. Use --ffmpeg-prefix to relink a recipient-modified FFmpeg build. Recipient signing and installation require separate matching Huawei credentials and have not been tested. The unchanged Rust parser materials retain the provenance limits in their notices.
